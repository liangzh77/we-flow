# 2026-05-20 自动发送微信终止记录

## 背景

2026-05-19 晚，技术探索阶段尝试过多个微信自动发送相关插件和 RPA/UI 自动化方案。最后一次 RPA 尝试确实发出了消息，但消息被发到了错误聊天会话。

2026-05-20，微信官方对账号发出警告。

## 决策

自动发送微信方向永久终止。

后续不再实现、测试或继续探索：

- RPA/UI 自动化控制微信发送
- 坐标点击、键盘、剪贴板、UIA、无障碍发送
- 自动搜索联系人或群聊
- 自动填入微信输入框
- 自动按 Enter 或点击发送
- 用户确认后由程序代按发送
- 自动把建议发送到文件传输助手、自己账号、好友或群聊
- `wxautox4`、`wechat-pc-auto`、`wxauto`、`wechat-auto` 等发送类库

## 允许范围

we-flow 后续只做：

- 只读读取本机微信聊天记录
- 增量读取新消息
- 白名单过滤
- 本地存储、搜索、摘要、分析
- 回复草稿生成
- 本地网页、桌面通知或其他不写入微信的提醒方式

## 插件和依赖处理

2026-05-20 已执行：

```powershell
py -m pip uninstall -y wxautox4 wechat-pc-auto wxauto wechat-auto
```

当前 Python 3.13 环境返回这些包均未安装。

Codex 插件缓存中只发现 `browser`、`chrome`、`github`，未发现微信自动发送类插件。
